# 今日 token 状态栏设计

## 意图与边界
用户要求将主状态栏的近 24h token 总量与缓存率改为今日 00:00 至当前，便于查看当日用量。
- 使用运行 Pi 的本机时区，日历日零点至本次查询开始时刻，两端包含。
- 两项统计使用同一窗口；跨日后下一次刷新重新从新一天零点统计。
- 保持当前模型列表、跨项目/跨会话已保存历史、去重、缓存率公式、显示格式及 250ms/60s 刷新机制。
- 不改变独立 `/token 24h` 和 `/token-usage` 命令。
- 保留 `usage24h` 配置键及内部控制器名称，兼容已保存布局；菜单和当前使用文档改为今日口径。

## Approaches
采用：仅在状态栏控制器中计算本地日历零点，复用现有 collector。范围 amount/unit 使用实际经过小时数，仅作为报告元数据。
不采用：更改共享 parseRange 或独立命令，会扩大用户要求的范围；重命名配置键会引入不必要的迁移。

## 实现方决定与验证
用 Date.setHours(0, 0, 0, 0) 得到本地零点，而非固定减去小时数，正确处理非 UTC 时区和夏令时。测试固定时钟、午夜包含/之前排除/未来排除、跨日与夏令时；同步生成脚本、生成源码、菜单测试及当前文档。历史设计与验证记录保留。

## 批准
用户已通过“按此修改”批准上述短设计。
